# GearForge Studio

브라우저에서 기어와 타이밍 풀리를 설계하고 2D/3D 파일로 내보내는 정밀 설계 도구입니다.

## 지원 기능

- 스퍼기어와 맞물림 기어
- 내접기어와 피니언
- 랙과 피니언
- 타이밍 벨트와 풀리 조합 계산
- 원형, 외접 6각, 키자리 중심 구멍
- 2D SVG/DXF 및 3D STL/3MF 내보내기
- 2D 회전 시뮬레이션과 드래그 가능한 3D 미리보기

## 실행

별도 설치나 서버가 필요하지 않습니다. `index.html`을 브라우저에서 열거나 GitHub Pages 배포본을 사용하세요.

## 주의

스퍼기어는 표준 전깊이 인벌류트 기반입니다. 내접기어와 타이밍 풀리의 BETA 치형은 실제 제작 전에 시제품으로 맞물림을 확인해야 합니다. 고하중 및 안전 핵심 부품은 전문적인 강도·간섭 검토가 필요합니다.
